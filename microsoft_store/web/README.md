# Último Refugio · edición PC

Juego de supervivencia zombi en pixel art isométrico. Esta es la edición para PC (Microsoft Store y navegador): gratis, sin anuncios y sin compras.

**Jugar:** https://edermichell.github.io/ultimo-refugio/

- Teclado y ratón o mando, en pantalla completa. Se juega sin conexión; el multijugador necesita internet.
- Política de privacidad: https://edermichell.github.io/privacidad/

Archivos: `index.html` (el juego), `manifest.webmanifest`, `sw.js` (caché sin conexión), `icons/` y `capturas/`.
